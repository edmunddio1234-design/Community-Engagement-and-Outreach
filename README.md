# Community Engagement & Outreach

Reach-out strategy, event calendar, contact directory, media plan and live tracker for the
Lighthouse Rural Community ecosystem across **Louisiana Region 9 and the Florida Parishes** —
East Baton Rouge, East Feliciana, West Feliciana, Livingston, St. Helena, St. Tammany,
Tangipahoa and Washington.

## Pages
| File | What it is |
|---|---|
| `index.html` | Strategy overview — the problem, the four moves, where the leverage is |
| `parishes.html` | The eight-parish footprint and why the state region line matters |
| `events.html` | Every event where a vendor table can reach veterans, with a live countdown |
| `contacts.html` | Clerks of court, parish councils, LDVA offices, aging network, faith associations |
| `media.html` | Media & marketing strategy — message, channels, outlet map, story bank, calendar |
| `tracker.html` | Interactive checklist; progress saved in the browser, exportable to CSV/JSON |

`docs/` holds the three print-ready PDFs.
